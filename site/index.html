How it works

One round of clickable questions, a one-page plan, then the build slice by slice. Your session wears each role's hat with short checklists, so it costs what a normal session costs. Want parallel agents? Team mode is one answer away, and it tells you it costs more.

  1. Intake

    One round of clickable questions: must-haves, stack, where it goes live, solo or team.

  2. Plan

    One page: stories, the look, the build, the tasks. The Lean checklist cuts what needn't exist.

  3. Build

    Slice by slice, with design polish built in and tests only where they pay. Nothing runs unwatched.

  4. Check and ship

    Tests, one review pass, a README with the badge, and a deploy to Vercel once you say go.

Meet the team

Each role is a short checklist your session follows in solo mode, and a dedicated agent in team mode. Specialists for databases, mobile, AI, payments, accessibility, performance and SEO join only when a project needs them.

Watch the team work, live

Knit Board follows the run log as it's written. Each station card shows who is working and what on. Files slide along the thread as agents hand them on; a file going backwards is a fix loop.

# live, while the team works
node board/server.mjs ../my-project
# replay a finished run
node board/server.mjs ../my-project --replay

Every run, reported

  • Run report: timeline, who handed what to whom, every agent run, debug loops and review rounds.
  • Benchmarked: the same calculator costs 117,960 tokens in a plain session and 124,120 with Knit.
  • Docs in Notion: brief, PRD, plan, design, quality, run and token reports, updated at every gate.
  • Your approval: after the plan, after every chunk, and before anything goes live.

Get started

Clone Knit, open Claude Code in the folder, and describe what you want. The team builds in a sibling folder and puts it live when you approve.

git clone https://github.com/jagdish3135/knit
cd knit && claude
# then, in Claude Code:
/knit-build a habit tracker with daily check-ins

# other tools: install into your project
node scripts/install.mjs cursor --target ../my-project
